# Пайплайн

В идеале при использовании пайплайна конструктор последовательно:


1) Разворачивает проект с присвоением какого-либо базового шифра
2) Формирует дерево 3Д-моделей с присвоением проектным (не стандартным или закупным) деталям и сборкам заготовки шифра, выдаёт им наименование (вроде "ШИФР.XXXX - Деталь такая")
3) Автонумерует проектные детали и сборки - "XXXX" заменяется на соответствующий номер, связи обновляются
4) Генерирует таблицу метадаты проекта, заполняет метадату по деталям (фамилии, числа, поставщики, ссылки)
5) Передаёт метадату из таблицы в проектные файлы дерева сборки
6) Редактирует спецификации в сборочных моделях
7) По шаблонным файлам для сборок и деталей генерирует заготовки чертежей с заполненными рамками и вставленным основным видом
8) Производит работу над чертежами
9) Выводит спецификации в xls-формате встроенными средствами inventor
10) Выводит STEP-файлы
11) Выводит DXF-файлы
12) Выводит чертежи
13) Выводит спецификации
14) Выводит закупную ведомость
15) Формирует общий вывод
16) Формирует пакеты файлов под конкретного контрагента
17) Формирует версии общего вывода и пакетов под контрагентов
18) Передаёт документы ответственным лицам

# Структура проекта

Текущая версия макросов отрабатывает при использовании структуры проекта:

```

└───PROJECT_X
    ├───0_Модели                                # Место хранения исходных проектных 3Д-моделей
    │   ├───STP                                 # Место вывода 3Д-моделей в универсальный формат STEP
    │   │   └───0_Архив
    │   └───Прочие изделия                      # Место хранения 3д-моделей стандартных или закупных изделий
    ├───1_Чертежи                               # Место хранения 2Д-графики
    │   ├───1_DWG                               # Место хранения чертежей в редактируемом формате
    │   ├───2_PDF                               # Место хранения текущей версии чертежей в PDF-формате
    │   │   └───0_Архив
    │   ├───3_DXF                               # Место хранения контурных чертежей под резку
    │   │   └───0_Архив
    │   └───4_СП                                # Место хранения спецификаций в PDF-формате
    │       ├───0_Архив     
    │       └───1_Редактируемый формат          # Место хранения промежуточного ред-формата спецификаций (вывода из Inventor в .xls)
    ├───2_Документы                             # Документы по проекту
    │   ├───1_Закупная ведомость               
    │   └───2_Паспорт изделия
    ├───3_Вывод                                 # Папка общего вывода
    │   ├───0_Архив                             # Версии общего вывода
    │   └───1_Пакеты на отправку                # Версии пакетов общего вывода         
    └───4_Прочее                                # Что-то ещё
        └───1_Шаблоны чертежей
            └───OldVersions

```
