# Inventor design project automatization macros


## Пакет макросов для автоматизации работы с Inventor

Комплекс для автоматизации работы по подготовке конструкторской документации в ЕСКД-стиле.

Предназначен для использования в случаях, когда энергозатраты на внедрение и ведение PDM-систем являются нерациональными


## Идея

В процессе выполнения конструкторского проекта инженер выполняет следующие рутинные действия:

1. Создание проекта
2. Заполнение метаданных деталей и сборок (обозначение, наименование, участники разработки...)
3. Формирование файлов чертежей, привязка моделей, заполнение рамок
4. Формирование спецификаций
5. Формирование ведомостей под закупку
6. Экспорт файлов (STEP, DXF, PDF...)
7. Формирование отдельных пакетов файлов для различных участников производственного цикла
8. Формирование закупной ведомости


Макросы в пакете выполняют отдельные опции, устраняющие необходимость производить рутинные репетативные действия, отнимающие время у инженера. В перспективе, пакет должен включать в себя:

1. Папка [diary](https://github.com/dimakomplekt/IDPAM_1.0/tree/main/diary) - место хранения описания всех реализованных макросов и инструкций по работе с ними.
2. Папка [macros](https://github.com/dimakomplekt/IDPAM_1.0/tree/main/macros) - место хранения исходных файлов всех реализованных макросов
3. Папка [project](https://github.com/dimakomplekt/IDPAM_1.0/tree/main/project) - место хранения примера проекта с исходной структурой и внедренными макросами
